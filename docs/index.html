moonfont reads font bytes and sets the letterforms it has measured.

A pure MoonBit font reader. No I/O, no platform font discovery, no C binding, no floating point. The same bytes produce the same coverage mask on wasm, wasm-gc, js and native, which is what makes a differential test meaningful.

The line above is not set in a web face. It is three sorts drawn from the outline commands parsed out of synthetic.ttf, at advances 600, 500 and 450 font units. Version 0.1.0 reads SFNT containers, TrueType glyf outlines and cmap formats 0, 4, 6 and 12; it deliberately does not shape text.

Eight packages, one direction

Dependency direction is strictly downwards. A lower layer never imports a higher one, and a lower layer never knows what a higher one is for. The counts are the declarations published in each interface.

  • moonbitstack/moonfont/model — domain vocabulary, 56 declarations
  • moonbitstack/moonfont/wire — bounded big-endian reads, 23 declarations
  • moonbitstack/moonfont/sfnt — container and table directory, 19 declarations
  • moonbitstack/moonfont/table — nine table decoders, 30 declarations
  • moonbitstack/moonfont/outline — path commands, 4 declarations
  • moonbitstack/moonfont/raster — coverage, 1 declaration
  • moonbitstack/moonfont/layout — measurement, 1 declaration
  • moonbitstack/moonfont — the façade, 27 declarations

One hundred and sixty-one declarations in total. Only the façade needs importing: decode, decode_all and the methods on Face re-export the twelve model types a caller needs.

Six sorts from synthetic.ttf. Advances and bearings are integer font units; ink coverage is a percentage of the 64 by 64 em square.

The face declares 9 tables and 6 glyphs, uses long loca and a format 4 cmap, and carries the magic word 0x5F0F3CF5. Its digest is f2e72b1c3adcf15f61e20a333d8c05eab337cae30bdd6d3932eb510faad4c0b1.
