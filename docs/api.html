Every package is a drawer and every declaration a compartment. The cast line comes from the interface; the note beside it comes from the source.

moonbitstack/moonfont

package

The façade. One import gives a caller the types, the entry points and the whole vertical slice from bytes to a coverage mask. Every package below is also public, so a caller that only needs charmap lookup or only needs a rasteriser does not have to load the rest.

Text measurement, not shaping. It sums advances and applies legacy kerning as data. Bidi, line breaking, GSUB/GPOS and syllable clustering are out of scope by design: those are a different library's problem.

moonbitstack/moonfont/raster

package

The one place that decides how geometry becomes coverage. It consumes path commands and knows nothing about SFNT, tables, charmaps or files.

fn

rasterise

pub fn rasterise(outline : @model.Outline, scale : @model.Scale, limits : @model.Limits) -> @model.CoverageMask raise @model.Refused

Turn an outline into eight-bit coverage at scale.

Each pixel row is sampled at eight vertical positions. At each of them the edges crossing that line are intersected, sorted and paired by non-zero winding; the horizontal span between a pair is accumulated into the pixels it covers as an exact 26.6 length. Eight samples times 64 units per pixel is 512, so the final scaling to 0..255 is exact and integer.

The whole window this cursor was bounded to, from its start rather than from its current position. A table that needs random access keeps this instead of seeking back and forth.

Cursor::u32

pub fn Cursor::u32(self : Cursor) -> Int32 raise @model.Refused

A 32-bit big-endian word. Font files are bounded by Limits.file_bytes well below 2 GiB, so a value with the high bit set is either corrupt or hostile; it arrives as a negative number and every caller's range check refuses it.
