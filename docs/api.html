package

The façade. One import gives a caller the types, the entry points and the whole vertical slice from bytes to a coverage mask. Every package below is also public, so a caller that only needs charmap lookup or only needs a rasteriser does not have to load the rest.

moonbitstack/moonfont/layout

package

Text measurement, not shaping. It sums advances and applies legacy kerning as data. Bidi, line breaking, GSUB/GPOS and syllable clustering are out of scope by design: those are a different library's problem.

The horizontal extent of a run of glyph ids, plus the font's vertical rhythm at the same size. Advances come from a function rather than a table because a variable font's advance depends on the location, and a caller that has no variation injects the constant width of the default instance.

Scale

pub(all) struct Scale { ppem : Int32 units_per_em : Int32 }
  • ppemInt32Pixels per em, in 26.6 fixed point.
  • units_per_emInt32

A size in 26.6 fixed point. The whole library computes with integers: a rasteriser that used floating point would produce different coverage on wasm, js and native for the same bytes, and a differential test could not say what the right answer is. The same scale serves measurement and rasterisation, so the two never disagree about where the pen stands, and a variable font's instance is resolved before a scale is applied.

fn

rasterise

pub fn rasterise(outline : @model.Outline, scale : @model.Scale, limits : @model.Limits) -> @model.CoverageMask raise @model.Refused

Turn an outline into eight-bit coverage at scale.

Each pixel row is sampled at eight vertical positions. At each of them the edges crossing that line are intersected, sorted and paired by non-zero winding; the horizontal span between a pair is accumulated into the pixels it covers as an exact 26.6 length. Eight samples times 64 units per pixel is 512, so the final scaling to 0..255 is exact and integer.

moonbitstack/moonfont/web

package

The web adapter. It re-exposes moonfont through a flat surface that a browser caller can use without constructing or introspecting MoonBit structs: every entry point takes and returns only primitives, Bytes or Strings. The CoverageMask and FontMetrics records it returns are read by field from JavaScript.

This package is a foreign library so the JS and WASM backends emit a loadable module whose named exports are the browser-facing surface below. Each export is pinned with #export_name so the names survive minification and are stable across backends.
