The point-size ruler and the em square, live.

Choose a size and a character. The sort is the path the engine returned from synthetic.ttf, and every reading on this page is a call into the engine compiled into it: outline_svg for the drawing, metrics for the advance and the bearing, scale_value for the 26.6 column.

Set the gauge

The slider sets pixels_per_em. Scale::of shifts it left by six bits; Scale::apply multiplies in 64 bits and truncates toward zero. The page asks the engine for that number rather than repeating the arithmetic, so the column below is the library's own answer.

A face with no sort for a codepoint is not an error: glyph_index returns None. The previous sort stays on the sheet until the .notdef box is chosen.
