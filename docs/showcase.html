The point-size ruler and the em square, live.

Choose a size and a character. The sort is drawn from the outline commands parsed out of synthetic.ttf, and every reading is recomputed with the library's own 26.6 integer arithmetic.

Set the gauge

The slider sets pixels_per_em. Scale::of shifts it left by six bits; Scale::apply multiplies in 64 bits and truncates toward zero, exactly as the MoonBit implementation does. Move the slider and the case table below changes with it.
